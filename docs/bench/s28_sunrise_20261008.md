## Method notes

- **Geometry:** the camera and card did not move, so one homography and one set of ColorChecker boxes serve all frames.
  - They were computed once on the Mac (`geometry.json`), because the Zero OOM-killed the full-frame multi-scale tag detection. Only that process died.
  - Every per-frame number was computed on the Pi.
- **ColorChecker grey row:** a ChArUco board covered it until ~09:50.
  - So noise is measured on the V3 greys: the std of (green − its 5×5 local mean) / mean, which excludes the light gradient.
  - The CC rows are flagged valid only from 09:50.
- **Wake estimate:** 9 s + capture + DNG read + prep + encode + (msgs + 2 + 40 heal chunks) × 1.3 s, then + 150 s. Real units trim the tail to the budget (bm `rc_command_hooks.py:389-396`).
